ကိုယ်ပိုင်ငွေစာရင်း — PWA Prototype (Version 1)

ပါဝင်သောအရာများ
- မြန်မာကျပ်ဖြင့် ဝင်ငွေ/ထွက်ငွေ/စုငွေ မှတ်တမ်း
- စာရင်းပြင်ဆင်ခြင်း၊ ဖျက်ခြင်း၊ ရက်စွဲ/အမျိုးအစား စစ်ထုတ်ခြင်း
- လစဉ်အနှစ်ချုပ်နှင့် ထွက်ငွေခွဲခြမ်းစိတ်ဖြာမှု
- Dark / Light Mode
- JSON Backup / Restore
- HTTPS hosting မှတစ်ဆင့် ဖွင့်ပြီးနောက် offline cache အသုံးပြုနိုင်ရန် PWA service worker

အရေးကြီးသော ကန့်သတ်ချက်များ
1. ဒီဖိုင်တွဲသည် ပထမဆုံး စမ်းသပ်ဗားရှင်းသာ ဖြစ်သည်။ ငွေကြေးအရေးကြီးသော အချက်အလက်များကို စတင်ထည့်မီ စမ်းသပ်ပါ။
2. ဒေတာကို လက်ရှိ Browser ၏ localStorage ထဲတွင် သိမ်းထားသည်။ Browser data/site data ဖျက်ခြင်း၊ app storage ရှင်းခြင်း၊ ဖုန်းပျောက်ခြင်းတို့ကြောင့် ဒေတာဆုံးရှုံးနိုင်သည်။ Backup ဖိုင်ကို ပုံမှန်ထုတ်ယူပြီး လုံခြုံသောနေရာတွင် သိမ်းပါ။
3. Backup ဖိုင်တွင် ငွေကြေးစာရင်းများ ပါဝင်သောကြောင့် အခြားသူထံ မပို့ပါနှင့်။
4. PWA install/offline အတွက် HTTPS hosting လိုအပ်သည်။ index.html ကို file manager မှ တိုက်ရိုက်ဖွင့်ရုံဖြင့် PWA installation/offline service worker အပြည့်အဝ အလုပ်လုပ်မည်ဟု မယူဆပါနှင့်။
5. “လက်ကျန်ငွေ” တွက်ချက်မှုမှာ မှတ်တမ်းစတင်သည့်နေ့မှ ဝင်ငွေ − ထွက်ငွေ − စုငွေသို့ လွှဲထားမှု + စုငွေမှ ပြန်ထုတ်မှုကို အခြေခံသည်။ စတင်လက်ကျန်ငွေ (opening balance) ထည့်သွင်းစနစ်ကို နောက်ဗားရှင်းတွင် ထည့်ရန် အကြံပြုသည်။

အသုံးပြုရန် အကြံပြုချက်
- ပထမဦးစွာ စမ်းသပ်ဒေတာအနည်းငယ်ဖြင့် ဝင်ငွေ၊ ထွက်ငွေ၊ စုငွေ စာရင်းများ ထည့်ပါ။
- Backup ဖိုင်ထုတ်ခြင်းနှင့် ပြန်ထည့်ခြင်းကို စမ်းသပ်ပါ။
- အမှန်တကယ်စာရင်းများ မထည့်မီ စာရင်းတွက်ချက်မှုမှန်ကန်ကြောင်း စစ်ဆေးပါ။
